# furima-finder（フリマおすすめ探し）

メルカリ（とラクマ）の出品から、**実際に売れた価格（相場）より安く出ている「買い」候補**を探して、点数の高い順に並べるツールです。
ポケモンカード向けには、**転売して利益が出るカード**を探すモードがあります（[ポケモンカードの転売候補を探す](#ポケモンカードの転売候補を探す)）。

```

  相場 ¥30,500（売り切れ 104件の中央値・10/02〜10/24・中央50%は ¥29,500〜¥36,000）
  状態別: 新品・未使用 ¥36,000（40件） / 美品 ¥30,000（50件）
  販売中 180件を確認 → おすすめ 12件（除外: 割安ではない 150件 / 専用・購入不可 5件 …）

   1. 71点 ¥23,800  相場比 -21%  [メルカリ]

      美品の相場 ¥30,000 より ¥6,200 安い / 未使用に近い / 送料込み / 出品 2時間前 / 出品者の評価 良い99.8%（421件）
      https://jp.mercari.com/item/m…
```

## ポケモンカードの転売候補を探す

`--profile pokeca` を付けると、ポケモンカード向けの判定に切り替わり、**相場で売った場合に利益が出るか**で採点します。

### いちばん簡単な使い方（Windows・ダブルクリック）

1. フォルダの中の **`pokeca_search.bat`** をダブルクリック → 1分ほどで結果がブラウザで開きます。
2. 見張り続けたいときは **`pokeca_watch.bat`** をダブルクリック → 15分ごとに検索し直して、新しく見つかった候補だけを黒い画面に表示します（結果のページはブラウザで F5 を押すと最新になります）。止めるときは黒い画面で `Ctrl + C` → 「バッチ ジョブを終了しますか」に `Y`。
3. 探す条件（キーワード・価格・最低利益）は **`pokeca.toml`** をメモ帳で開いて書き換え、上書き保存します。

コマンドで細かく指定する場合は次のとおりです。

```bash
# スキャン: 「SAR」の新着出品をまとめて集め、カード番号ごとに売り切れ相場を調べて利益が出るものを探す
python -m furima_finder --profile pokeca --scan "ポケモンカード SAR" --min-price 2000 --max-price 30000 --html pokeca.html

# 狙い撃ち: 特定のカードを見張る（カード名＋レアリティ＋カード番号で）
python -m furima_finder --profile pokeca "リザードンex SAR 201/165"

# 見本のリストで、15分ごとに新着の候補だけをチェックして Discord に通知
python -m furima_finder --config watchlist.pokeca.example.toml --watch 15 --webhook "https://discord.com/api/webhooks/…"
```

### ポケカ用の判定

- **鑑定品と未鑑定を混ぜない**：PSA10 / PSA9 / その他の鑑定品 / 未鑑定、BOX はシュリンク付き / なし / 不明で相場を分け、同じ種類の売り切れがない出品は比べません。「PSA10狙い」「鑑定用」は未鑑定として扱います。
- **除外するもの**：オリパ、プロキシ・ファンアートなどの非公式品、海外版（英語版・韓国版・中国版など）、まとめ売り・〇枚セット・デッキ、スリーブなどのサプライ品、レアリティやカード番号が書かれておらずカードを特定できない出品。
- **注意として出すもの**：初期傷・白欠け・反り・折れ、BOX の「再シュリンク」「サーチ済み」など。
- **スキャン**：新着の出品を最大240件集めてカード番号（`201/165` や `001/SV-P`）ごとにまとめ、新しい出品があるカードから20種類（`--scan-cards`）の売り切れを調べます。タイトルにカード番号がない出品は対象外です。1回のスキャンで、販売中の検索2回＋カードの種類数ぶんの売り切れ検索＋上位10件の詳細確認を、1.5秒以上の間隔をあけて行います（20種類なら1分弱）。

### 転売目線の採点（100点満点）

| 項目 | 配点 | 内容 |
|---|---|---|
| 利益額 | 35点 | 売値の目安 ×（1 − 手数料10%）− 送料 − 仕入れ値。1万円以上で満点 |
| 利益率 | 20点 | 利益 ÷ 仕入れ値。60%以上で満点 |
| 売れ行き | 15点 | 直近30日に売れた件数（30件以上で満点）。売れにくいカードは在庫になりやすいため |
| 相場の動き | 10点 | 直近7日の中央値をそれ以前（30日まで）と比べる。下がっていれば0点 |
| 状態 | 10点 | 傷・汚れありは注意も表示 |
| 出品者 | 10点 | 良い評価の割合と件数 |

- **売値の目安**は直近14日の売り切れの中央値です（件数が少なければ全体の中央値）。価格のばらつきが大きいときは、控えめに下位25%の価格を使います。
- 既定では **利益1,000円未満・利益率15%未満・直近30日の販売3件未満** を候補から外します（`--min-profit` `--min-roi` `--min-sales` で変更）。
- 送料はカード1枚 230円（ネコポス 210円＋資材）、BOX は 520円で計算します（`--resale-shipping` で変更）。
- 状態が悪いカードは相場どおりには売れないので、売値を「やや傷や汚れあり」は相場の70%、「傷や汚れあり」は50%、「全体的に状態が悪い」は30%で計算します。説明文に「折れ」「水濡れ」などがあれば減点します（「折れや水濡れはありません」のような否定は除く）。
- オークション出品は入札数・残り時間と「ここまでで落札できれば利益が出る」入札上限の目安を表示し、即決で買える出品の後ろに並べます。
- `--resale` を付ければ、ポケカ以外の商品でもこの採点が使えます。

### 転売する前に（法律と規約）

- **古物商許可**：利益を目的に中古品を仕入れて売ることを繰り返す場合は、古物営業法により都道府県の公安委員会の許可（古物商許可）が必要です。無許可の場合は罰則（3年以下の拘禁刑または100万円以下の罰金）があります。
- **メルカリの規約**：2025年10月22日の改定で、事業者（継続的に転売・せどりをする個人事業主を含む）はフリマアプリ「メルカリ」を使えず、「メルカリShops」への出店が必要になりました。
- 当てはまるか迷う場合は、お住まいの地域の警察署（古物商の窓口）やメルカリのヘルプで確認してください。

## 対応サイト

| サイト | 指定名 | できること | 状態 |
|---|---|---|---|
| メルカリ | `mercari` | 販売中を探す・売り切れから相場を出す・出品者評価や説明文の確認 | 動作確認済み |
| ラクマ | `rakuma` | 販売中を探す・売り切れから相場を出す | 取得を確認済み |
| Yahoo!フリマ | `yahoo` | 販売中を探す（相場はメルカリ・ラクマの売り切れを使う） | 取得を確認済み |
| スニダン | `snkrdunk` | 商品ごとの最安値を探す（状態・手数料・送料は商品ページで確認） | 取得を確認済み |

使うサイトは `--sources mercari,rakuma,yahoo,snkrdunk` か、設定ファイルの `sources = [...]` で選びます（`pokeca.toml` の既定は4サイトすべて、コマンドで動かすときの既定はメルカリだけ）。
Yahoo!フリマは検索結果に出品者の評価（良い評価の割合と件数）が入っているので、それも採点に使います。
各サイトのページの作りが変わると取れなくなることがあります。そのときも下の診断で状況を確認できます。
**`check_sites.bat` をダブルクリック**（または `python -m furima_finder --probe`）すると、各サイトから取得できるか、
ページがどんな形かを表示します（取得したページは `probe` フォルダに保存）。その表示があれば読み取り方を直せます。

## しくみ

1. **相場を調べる** — 同じキーワードの「売り切れ」の出品を最大240件集め、中央値を相場とします。
   - 「箱のみ」「説明書のみ」「ジャンク」など、本体そのものではない・状態が違う出品は除外
   - タイトルにキーワードが半分以上含まれていない出品は除外（無関係な商品を混ぜないため）
   - 極端に安い/高い出品（まとめ売りなど）は外れ値として除外
   - 件数が足りれば「新品・未使用」「美品」「傷・汚れあり」の状態別にも相場を出し、比較に使います
2. **販売中を集める** — 相場から見て割安になりうる価格帯（既定では相場の30%〜90%）の出品だけを取りに行きます。
3. **採点する（100点満点）** — 以下は「お得に買う」ための既定の採点です（転売目線の採点は[上](#転売目線の採点100点満点)）。
   | 項目 | 配点 | 内容 |
   |---|---|---|
   | 価格 | 55点 | 相場より何%安いか（40%以上安いと満点）。着払いは想定送料を足して比較 |
   | 状態 | 15点 | 新品・未使用が最高 |
   | 出品者 | 15点 | 良い評価の割合と件数。メルカリShopsは10点 |
   | 新しさ | 10点 | 出品から3時間以内が最高（安い新着はすぐ売れるため） |
   | 送料 | 5点 | 送料込みなら加点 |

   さらに、タイトルの「ジャンク」「故障」（-30点）、「動作未確認」「訳あり」（-12点）、オークション形式（-20点）を減点します。
   「〇〇様専用」「購入不可」「箱のみ」などは候補から外します。
4. **上位を詳しく確認する** — 上位10件は商品ページの情報（出品者の評価・説明文・いいね数・売り切れかどうか）を取り直して採点し直します。説明文に「動作未確認」などがあれば注意として表示します。

## 準備

Python 3.11 以上が必要です（[python.org](https://www.python.org/downloads/) から入れられます。Windows では「Add python.exe to PATH」にチェック）。

```bash
git clone https://github.com/x954955-art/-.git furima-finder
cd furima-finder
pip install -r requirements.txt
```

`pip install -e .` でインストールすると、`python -m furima_finder` の代わりに `furima-finder` コマンドでも動きます。

## 使い方

```bash
# 基本
python -m furima_finder "Nintendo Switch 有機EL"

# 安い周辺機器・ソフトを除き、予算と状態を指定して、写真付きのレポートも保存
python -m furima_finder "Nintendo Switch 有機EL" --min-price 15000 --max-price 30000 --condition good --html report.html

# 相場より20%以上安いものだけ。ラクマも検索
python -m furima_finder "AirPods Pro 第2世代" --min-discount 20% --sources mercari,rakuma

# 複数のキーワードをまとめて
python -m furima_finder "iPad mini 6 64GB" "AirPods Pro 第2世代" --csv result.csv
```

`--html` で保存したファイルをブラウザで開くと、写真・割引率・注意点つきのカードで一覧でき、「おすすめ順 / 割引率 / 安い順 / 新着順」で並べ替えられます。`--csv` は Excel でそのまま開けます。

### 主なオプション

| オプション | 意味 | 既定 |
|---|---|---|
| `--min-price` / `--max-price` | 価格の下限 / 上限（予算）。下限は相場の計算にも使います | なし |
| `--condition` | 状態の下限：`new` 新品・未使用 / `near-new` 未使用に近い以上 / `good` 目立った傷や汚れなし以上 / `fair` やや傷や汚れあり以上 | 指定なし |
| `--exclude` | 除外キーワード（例 `--exclude "ジャンク 箱のみ"`） | なし |
| `--min-discount` | 相場より何%以上安ければ候補にするか（`15%`・`15`・`0.15` どれでも可） | 10% |
| `--market-price` | 相場を自分で決める（売り切れから計算しない） | なし |
| `--sources` | 検索するサイト（`mercari`, `rakuma`, `yahoo`, `snkrdunk`）。rakuma 以降は実験的 | mercari |
| `--details` | 上位何件の出品者評価・説明文を確認するか（0 で確認しない） | 10 |
| `--top` | 表示件数 | 20 |
| `--html` / `--csv` / `--json` | 結果をファイルに保存 | なし |
| `--profile` | 商品ジャンル：`default`（一般）/ `pokeca`（ポケモンカード） | default |
| `--scan` | キーワードを「探す範囲」にして、見つかったカードごとに相場を調べる（`--profile pokeca` 用） | なし |
| `--resale` / `--no-resale` | 転売目線（利益・利益率・売れ行き）で採点する | pokeca ではオン |
| `--min-profit` / `--min-roi` / `--min-sales` | 転売目線で候補にする利益・利益率・直近30日の販売数の下限 | 500円（pokeca 1,000円）/ 15% / 3件 |

全部のオプションは `python -m furima_finder --help` で確認できます。

### 探したい商品をファイルにまとめる

[`watchlist.example.toml`](watchlist.example.toml) をコピーして編集し、`--config` で指定します。

```toml
[defaults]
min_discount = "15%"
exclude = ["ジャンク", "部品取り"]

[[search]]
keyword = "Nintendo Switch 有機EL"
min_price = 15000
max_price = 32000
condition = "good"

[[search]]
keyword = "iPad mini 6 64GB"
min_price = 30000
```

```bash
python -m furima_finder --config watchlist.toml --html report.html
```

値は「`[defaults]` < 各 `[[search]]` < コマンドラインで指定した値」の順に優先されます（除外キーワードは足し合わせ）。

### 新着を見張る（監視モード）

安い出品はすぐ売れるので、定期的に検索し直して**新しく見つかった候補だけ**を表示できます（間隔は最短5分）。

```bash
python -m furima_finder --config watchlist.toml --watch 15
```

Discord や Slack の Webhook URL を渡すと、新着候補をスマホにも通知できます。

```bash
python -m furima_finder --config watchlist.toml --watch 15 --webhook "https://discord.com/api/webhooks/…"
```

止めるときは Ctrl+C です。

## 精度を上げるコツ

- **キーワードは具体的に**：「Switch」より「Nintendo Switch 有機EL ホワイト」、「iPhone」より「iPhone 15 128GB SIMフリー」。相場が混ざらなくなります。
- **`--min-price` で付属品を除く**：本体を探しているのにケースやソフトが相場に混ざると、相場が低く出てしまいます。「価格のばらつきが大きいです」と表示されたら設定してみてください。
- **状態をそろえる**：`--condition good` などを付けると、相場と候補の両方がその状態以上に絞られます。

## うまくいかないとき

| 表示 | 考えられる原因と対処 |
|---|---|
| `HTTP 403: アクセスを拒否されました` | メルカリ側の仕様変更か、アクセスが多すぎて一時的に制限された可能性があります。時間をおくか `--interval 3` で間隔を広げてください。続く場合は仕様変更の可能性があります |
| `プロキシに接続を拒否されました` / `接続できません` | インターネット接続（会社のネットワークのプロキシ制限など）を確認してください |
| `相場: 算出できませんでした` | 売り切れの出品が少なすぎます。キーワードを短くするか、`--market-price 30000` のように相場を指定してください |
| おすすめが0件 | `--min-discount 5%` に下げる、`--max-price` を上げる、キーワードを変える |
| 「キーワード不一致」で除外される件数が多い | タイトルに検索語の半分以上が入っていない出品は除外しています。表記ゆれ（「スイッチ」と「Switch」など）が多い商品は `--min-match 0.3`（0 で判定しない）に下げてください |
| ラクマの結果が出ない | ラクマはページの構造を読んでいるため、サイトのデザイン変更で取れなくなることがあります（実験的機能） |
| ポケカのスキャンでおすすめが0件 | 利益の出る出品はすぐ売れるため、0件のことも多いです。`--watch` で定期的に見張るか、`--min-profit 500` に下げる、`--scan-cards 40` で調べるカードを増やす、キーワードのレアリティ（SAR・SR・AR・MUR など）を変える |
| 「カード番号なし」「カードを特定できない」で除外が多い | タイトルにカード番号やレアリティがない出品は、どのカードか分からず相場と比べられないため外しています |
| 「相場不明」が多い | 鑑定品（PSA10 など）は同じ種類の売り切れがないと比べません。狙い撃ちのときは `PSA10 リザードンex SAR 201/165` のように鑑定の種類もキーワードに入れてください |

## 注意事項

- **購入前に必ず商品ページを確認してください。** 点数は機械的な目安です。相場より大幅に安い出品には、偽物・説明と違う状態・詐欺などが混ざることもあります。
- メルカリ・ラクマの公式APIではなく、Webサイトと同じ通信を使っています。サイトの仕様変更で動かなくなることがあります。
- サイトに負荷をかけないよう、リクエストは既定で1.5秒以上の間隔をあけ、1回の検索で取りに行く件数も抑えています。**個人で使う範囲にとどめ、間隔を短くしすぎないでください。** 利用前に各サービスの利用規約もご確認ください。
- 転売目線の利益は「相場の価格で売れた場合」の目安です。実際には値下げ交渉や相場の下落で下回ることがあります。転売を続ける場合は[法律と規約](#転売する前に法律と規約)も確認してください。

```
    snkrdunk.py   スニダン（検索ページの埋め込みJSON・実験的）
    embedded.py   ページに埋め込まれたJSONから商品の並びを探す共通処理
  probe.py        各サイトの取得診断（--probe）
```

新しいサイトを足すときは `sources/` に `search()` と `fetch_details()` を持つクラスを作り、`sources/__init__.py` の `AVAILABLE` に登録します。
