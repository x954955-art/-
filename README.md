# furima-finder（フリマおすすめ探し）

メルカリ（とラクマ）の出品から、**実際に売れた価格（相場）より安く出ている「買い」候補**を探して、点数の高い順に並べるツールです。

```
■「Nintendo Switch 有機EL」  2026/10/24 21:30 時点
  相場 ¥30,500（売り切れ 104件の中央値・10/02〜10/24・中央50%は ¥29,500〜¥36,000）
  状態別: 新品・未使用 ¥36,000（40件） / 美品 ¥30,000（50件）
  販売中 180件を確認 → おすすめ 12件（除外: 割安ではない 150件 / 専用・購入不可 5件 …）

   1. 71点 ¥23,800  相場比 -21%  [メルカリ]
      Nintendo Switch 有機ELモデル ホワイト 美品 付属品完備
      美品の相場 ¥30,000 より ¥6,200 安い / 未使用に近い / 送料込み / 出品 2時間前 / 出品者の評価 良い99.8%（421件）
      https://jp.mercari.com/item/m…
```

（上の出力は表示の例です。数値は実際の検索結果ではありません）

## しくみ

1. **相場を調べる** — 同じキーワードの「売り切れ」の出品を最大240件集め、中央値を相場とします。
   - 「箱のみ」「説明書のみ」「ジャンク」など、本体そのものではない・状態が違う出品は除外
   - タイトルにキーワードが半分以上含まれていない出品は除外（無関係な商品を混ぜないため）
   - 極端に安い/高い出品（まとめ売りなど）は外れ値として除外
   - 件数が足りれば「新品・未使用」「美品」「傷・汚れあり」の状態別にも相場を出し、比較に使います
2. **販売中を集める** — 相場から見て割安になりうる価格帯（既定では相場の30%〜90%）の出品だけを取りに行きます。
3. **採点する（100点満点）**
   | 項目 | 配点 | 内容 |
   |---|---|---|
   | 価格 | 55点 | 相場より何%安いか（40%以上安いと満点）。着払いは想定送料を足して比較 |
   | 状態 | 15点 | 新品・未使用が最高 |
   | 出品者 | 15点 | 良い評価の割合と件数。メルカリShopsは10点 |
   | 新しさ | 10点 | 出品から3時間以内が最高（安い新着はすぐ売れるため） |
   | 送料 | 5点 | 送料込みなら加点 |

   さらに、タイトルの「ジャンク」「故障」（-30点）、「動作未確認」「訳あり」（-12点）、オークション形式（-20点）を減点します。
   「〇〇様専用」「購入不可」「箱のみ」などは候補から外します。
4. **上位を詳しく確認する** — 上位10件は商品ページの情報（出品者の評価・説明文・いいね数・売り切れかどうか）を取り直して採点し直します。説明文に「動作未確認」などがあれば注意として表示します。

## 準備

Python 3.11 以上が必要です（[python.org](https://www.python.org/downloads/) から入れられます。Windows では「Add python.exe to PATH」にチェック）。

```bash
git clone https://github.com/x954955-art/-.git furima-finder
cd furima-finder
pip install -r requirements.txt
```

`pip install -e .` でインストールすると、`python -m furima_finder` の代わりに `furima-finder` コマンドでも動きます。

## 使い方

```bash
# 基本
python -m furima_finder "Nintendo Switch 有機EL"

# 安い周辺機器・ソフトを除き、予算と状態を指定して、写真付きのレポートも保存
python -m furima_finder "Nintendo Switch 有機EL" --min-price 15000 --max-price 30000 --condition good --html report.html

# 相場より20%以上安いものだけ。ラクマも検索
python -m furima_finder "ポケモンカード 151 BOX" --min-discount 20% --sources mercari,rakuma

# 複数のキーワードをまとめて
python -m furima_finder "iPad mini 6 64GB" "AirPods Pro 第2世代" --csv result.csv
```

`--html` で保存したファイルをブラウザで開くと、写真・割引率・注意点つきのカードで一覧でき、「おすすめ順 / 割引率 / 安い順 / 新着順」で並べ替えられます。`--csv` は Excel でそのまま開けます。

### 主なオプション

| オプション | 意味 | 既定 |
|---|---|---|
| `--min-price` / `--max-price` | 価格の下限 / 上限（予算）。下限は相場の計算にも使います | なし |
| `--condition` | 状態の下限：`new` 新品・未使用 / `near-new` 未使用に近い以上 / `good` 目立った傷や汚れなし以上 / `fair` やや傷や汚れあり以上 | 指定なし |
| `--exclude` | 除外キーワード（例 `--exclude "ジャンク 箱のみ"`） | なし |
| `--min-discount` | 相場より何%以上安ければ候補にするか（`15%`・`15`・`0.15` どれでも可） | 10% |
| `--market-price` | 相場を自分で決める（売り切れから計算しない） | なし |
| `--sources` | 検索するサイト（`mercari`, `rakuma`） | mercari |
| `--details` | 上位何件の出品者評価・説明文を確認するか（0 で確認しない） | 10 |
| `--top` | 表示件数 | 20 |
| `--html` / `--csv` / `--json` | 結果をファイルに保存 | なし |
| `--resale` | 相場で売った場合の利益の目安（手数料10%・送料750円を差し引き）も表示 | なし |

全部のオプションは `python -m furima_finder --help` で確認できます。

### 探したい商品をファイルにまとめる

[`watchlist.example.toml`](watchlist.example.toml) をコピーして編集し、`--config` で指定します。

```toml
[defaults]
min_discount = "15%"
exclude = ["ジャンク", "部品取り"]

[[search]]
keyword = "Nintendo Switch 有機EL"
min_price = 15000
max_price = 32000
condition = "good"

[[search]]
keyword = "iPad mini 6 64GB"
min_price = 30000
```

```bash
python -m furima_finder --config watchlist.toml --html report.html
```

値は「`[defaults]` < 各 `[[search]]` < コマンドラインで指定した値」の順に優先されます（除外キーワードは足し合わせ）。

### 新着を見張る（監視モード）

安い出品はすぐ売れるので、定期的に検索し直して**新しく見つかった候補だけ**を表示できます（間隔は最短5分）。

```bash
python -m furima_finder --config watchlist.toml --watch 15
```

Discord や Slack の Webhook URL を渡すと、新着候補をスマホにも通知できます。

```bash
python -m furima_finder --config watchlist.toml --watch 15 --webhook "https://discord.com/api/webhooks/…"
```

止めるときは Ctrl+C です。

## 精度を上げるコツ

- **キーワードは具体的に**：「Switch」より「Nintendo Switch 有機EL ホワイト」、「iPhone」より「iPhone 15 128GB SIMフリー」。相場が混ざらなくなります。
- **`--min-price` で付属品を除く**：本体を探しているのにケースやソフトが相場に混ざると、相場が低く出てしまいます。「価格のばらつきが大きいです」と表示されたら設定してみてください。
- **状態をそろえる**：`--condition good` などを付けると、相場と候補の両方がその状態以上に絞られます。

## うまくいかないとき

| 表示 | 考えられる原因と対処 |
|---|---|
| `HTTP 403: アクセスを拒否されました` | メルカリ側の仕様変更か、アクセスが多すぎて一時的に制限された可能性があります。時間をおくか `--interval 3` で間隔を広げてください。続く場合は仕様変更の可能性があります |
| `プロキシに接続を拒否されました` / `接続できません` | インターネット接続（会社のネットワークのプロキシ制限など）を確認してください |
| `相場: 算出できませんでした` | 売り切れの出品が少なすぎます。キーワードを短くするか、`--market-price 30000` のように相場を指定してください |
| おすすめが0件 | `--min-discount 5%` に下げる、`--max-price` を上げる、キーワードを変える |
| 「キーワード不一致」で除外される件数が多い | タイトルに検索語の半分以上が入っていない出品は除外しています。表記ゆれ（「スイッチ」と「Switch」など）が多い商品は `--min-match 0.3`（0 で判定しない）に下げてください |
| ラクマの結果が出ない | ラクマはページの構造を読んでいるため、サイトのデザイン変更で取れなくなることがあります（実験的機能） |

## 注意事項

- **購入前に必ず商品ページを確認してください。** 点数は機械的な目安です。相場より大幅に安い出品には、偽物・説明と違う状態・詐欺などが混ざることもあります。
- メルカリ・ラクマの公式APIではなく、Webサイトと同じ通信を使っています。サイトの仕様変更で動かなくなることがあります。
- サイトに負荷をかけないよう、リクエストは既定で1.5秒以上の間隔をあけ、1回の検索で取りに行く件数も抑えています。**個人で使う範囲にとどめ、間隔を短くしすぎないでください。** 利用前に各サービスの利用規約もご確認ください。
- `--resale` の利益は「相場で売れた場合」の単純な目安です。メルカリは2025年10月22日の利用規約改定で、事業者（継続的な転売・せどりを含む）は「メルカリ」ではなく「メルカリShops」を使うことになっています。

## 開発者向け

```bash
pip install -e ".[dev]"
pytest
```

テストは通信を一切せず、用意した応答データで動きます。

```
furima_finder/
  cli.py          コマンドライン・設定ファイル・監視モード
  finder.py       1キーワード分の流れ（相場 → 販売中 → 採点 → 上位の詳細確認）
  market.py       売り切れ価格からの相場推定（外れ値除外・状態別）
  scoring.py      採点ルール
  text.py         タイトル・説明文の判定ルール（専用・箱のみ・ジャンク等）
  report.py       ターミナル・HTML・CSV・JSON 出力
  notify.py       Discord / Slack 通知
  http.py         間隔・リトライ付きの通信
  sources/
    mercari.py    メルカリ（Web版と同じAPI。DPoP署名付き）
    rakuma.py     ラクマ（検索結果ページの解析・実験的）
```

新しいサイトを足すときは `sources/` に `search()` と `fetch_details()` を持つクラスを作り、`sources/__init__.py` の `AVAILABLE` に登録します。
